# Dados e proveniência

## Disponível

`seeg_mt_2024_transcricao.csv` contém **transcrição manual de valores publicados**, NÃO é um download do CSV original da plataforma. Fonte: https://plataforma.seeg.eco.br/territorio/mato-grosso, coleção 13.0, GWP-AR5, ano 2024. Valores obtidos/consultados em 18/10/2026. São as cinco parcelas brutas: mudança de uso da terra, agropecuária, energia, resíduos e processos industriais. O total bruto publicado é **231.174.595,84 tCO₂e** e as remoções são **59.261.547,00 tCO₂e**. O total é mostrado no código como 231.17459584 MtCO₂e. Não tratar transcrição como banco integral.

## Dados originais indisponíveis

O material recebido contém somente o HTML já compilado. **Não vieram** os arquivos CSV originais NASA GISTEMP, NOAA, Global Carbon Project, Climate Watch, SEEG, populações/consumo, nem os scripts de extração. Parte dos dados está embutida como arrays dentro do JavaScript do HTML. Não é correto alegar download ou verificabilidade linha a linha a partir de CSVs que não foram fornecidos.

Para uma auditoria reprodutível, anexar os arquivos brutos originais com URLs, data de download, versão, licença, hash e instruções de processamento. Isso deve anteceder o uso dos resultados como base de artigo científico.
